# 二期自动寻路打怪范围

二期不进入一期实现，但一期必须保留攻击触发策略和观察接口边界。定点“识别怪物后攻击”是一期之后、完整自动寻路之前可以独立交付的增强：它只替换攻击触发策略，不增加地图寻路。

## 目标

- OpenCV 负责实时采集与基础 HUD/几何处理。
- YOLO 负责 Self、其他玩家、怪物等目标识别。
- 识别开关打开后，持续攻击和实时预览共用识别会话；React 主窗口显示角色名称、等级、职业、HP/MP/EXP、置信度和新鲜度，原生预览显示动态识别框、FPS、帧龄和故障诊断。
- 单站地图内识别楼层、平台、边界和怪物位置。
- 基于最新观察生成局部移动动作，移动到攻击范围后攻击。
- 不是预先录制的固定按键脚本；每个动作都受窗口、安全门、观察新鲜度和输入 Broker 约束。

## 与一期的关系

- 复用 WindowLocator、Broker、keybd_event、通知、日志和 React bridge。
- 不复用一期“始终攻击”作为识别模式的隐式后备。
- 识别模式可以使用短攻击动作或按技能反馈触发，不要求长按。
- 定点模式的移动节奏规划器可以继续使用，但自动寻路拥有不同的导航策略，不得共用错误的“站桩安全范围”假设。

## 未达成前不得启用

真实 Windows 采集、模型准确率、目标过滤（Player 永不成为攻击目标）、地图验证和闭环稳定性未达到验收标准前，识别攻击模式保持 disabled。

## 当前实现进度

- [x] 地图包只读加载：校验 `manifest.json`/`map.json`、平台、梯子、连线和怪物模板元数据。
- [x] 地图包加载边界：拒绝非法归档路径、超限条目、重复 ID、悬空平台引用和错误格式/版本。
- [x] 观察录制器：实时预览可在不发送输入的情况下采样画面，自动提取稳定平台/梯子候选并导出 `.mapzip`。
- [x] 录制几何以左上角小地图为全局坐标来源；现有识别模型的 `environment` 输出只负责当前屏幕的局部平台/梯子校验，过滤 HUD、背景纹理和悬空候选，并输出地图质量结论。
- [x] 录制拓扑严格验证：合并同层重叠平台；每条导航梯子必须由小地图候选、本地角色邻近证据和实际纵向轨迹共同验证；存在未验证连接或平台图不连通时禁止规划。
- [x] 通用地图目录与手动地图选择：只读加载用户目录中的合法 `.mapzip`，文件名与包内名称不一致时禁止运行，不得硬编码地图或桌面路径。
- [x] 将选定地图快照接入固定 ROI 地图匹配、角色小地图定位和当前平台判定；支持 `1366×768` 逻辑坐标到等比 DPI 物理帧的投影。
- [x] 兼容 `madudu_map_package v1 / app_version 1.0.0` 的外窗坐标：包内小地图 ROI 包含 32px 标题栏基准，投影到已裁剪客户区的 WGC 帧前统一扣除该顶部偏移；不得按地图名称或具体坐标特判。
- [x] 基于梯子连通图实现 A*、最久未访问平台巡逻和短动作闭环移动；首版不使用跳跃、下跳、传送门或特殊移动技能。
- [x] 启动时角色位于包未登记的窄落脚点且无法归属平台时，优先向同高度、水平距离不超过 12 个地图像素的唯一最近平台执行短距离横移恢复；最近距离并列或超界时安全停止。
- [x] `MoveDown` 只允许用于黄点已确认落在包内梯子范围的上下梯闭环；未知落脚点不得把单独 `Down` 当成下跳或穿平台动作，首版不发送 `Down+Jump`。
- [x] 导航动作后只消费按键释放至少 150ms 后捕获的新帧作为位移反馈；动作期间和刚释放的帧不重复发键，不计入 `NAVIGATION_STUCK`。
- [x] 启动定位必须经过连续 5 帧地图匹配且角色黄点存在的稳定握手；地图结构仍匹配但黄点短暂闪烁/遮挡时保持 `MAP_VALIDATION_PENDING`，不得绕过 3 秒有界预检直接停止。
- [x] 联合包内怪物模板和现有识别结果，只接近并攻击同平台怪物；无怪时继续全图巡逻。
- [ ] 在沼泽地3完成一次完整 Windows 运行验收：多平台巡逻、上下梯、接近攻击和异常安全释放。产品不提供只观察或单连接运行模式。

自动化与离线实帧证据见 [`phase-2/evidence/map-package-auto-navigation.md`](phase-2/evidence/map-package-auto-navigation.md)。最后一项只能由已登录、处于目标地图的真实客户端完成，不得以模拟结果替代。
