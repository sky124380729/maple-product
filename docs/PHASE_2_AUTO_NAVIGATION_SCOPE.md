# 二期自动寻路打怪范围

二期不进入一期实现，但一期必须保留攻击触发策略和观察接口边界。定点“识别怪物后攻击”是一期之后、完整自动寻路之前可以独立交付的增强：它只替换攻击触发策略，不增加地图寻路。

## 目标

- OpenCV 负责实时采集与基础 HUD/几何处理。
- YOLO 负责 Self、其他玩家、怪物等目标识别。
- 单站地图内识别楼层、平台、边界和怪物位置。
- 基于最新观察生成局部移动动作，移动到攻击范围后攻击。
- 不是预先录制的固定按键脚本；每个动作都受窗口、安全门、观察新鲜度和输入 Broker 约束。

## 与一期的关系

- 复用 WindowLocator、Broker、keybd_event、通知、日志和 React bridge。
- 不复用一期“始终攻击”作为识别模式的隐式后备。
- 识别模式可以使用短攻击动作或按技能反馈触发，不要求长按。
- 定点模式的移动节奏规划器可以继续使用，但自动寻路拥有不同的导航策略，不得共用错误的“站桩安全范围”假设。

## 未达成前不得启用

真实 Windows 采集、模型准确率、目标过滤（Player 永不成为攻击目标）、地图验证和闭环稳定性未达到验收标准前，识别攻击模式保持 disabled。
