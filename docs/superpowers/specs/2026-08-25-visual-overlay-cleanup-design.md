# 视觉框选覆盖层精简设计

## 目标

视觉安全区框选和实时跟踪时，游戏画面必须保持可辨认、可精确拖拽。覆盖层不能用文字遮挡人物、平台或特效。

## 范围

- 黄色平台外框、绿色安全核心、蓝色人物模板、青色可信本人和橙色候选继续保留原有坐标、颜色和透明填充。
- 所有视觉配置覆盖框、实时视觉覆盖框和拖拽临时框不创建文字标签。
- 绿色框由 Host 自动计算。框内允许双向随机移动；黄色与绿色之间只允许向内修正；黄色之外冻结移动。
- 颜色图例、框选步骤、校准进度、错误和保存结果保留在预览工具栏或底部状态栏，不覆盖游戏画面。
- 实时人物匹配分数保留在底部状态栏，不再附着在青色或橙色框上。

## 不变边界

- 不修改视觉配置 schema、磁盘路径、人物模板、匹配阈值、安全门、移动控制、随机算法、Broker 或 React bridge。
- 不修改普通人物和怪物识别框，本轮只精简视觉平台保护覆盖层。
- 清空配置、重新配置、采样和运行期禁止修改等生命周期规则保持不变。

## 验证

- 覆盖层布局测试证明所有视觉覆盖项不再携带可显示标签。
- WindowsHost 构建证明 WPF 覆盖层只创建矩形，不再创建文字控件。
- 既有视觉观察、配置保存和会话控制测试保持通过。
