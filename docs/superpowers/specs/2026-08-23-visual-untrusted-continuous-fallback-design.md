# 视觉失信位置预测回退设计

## 目标

视觉增强持续攻击中，用每次可信视觉位移和 Broker 返回的真实方向键按压时长在线校准左右方向的 `px/ms`。本人人物外观连续 15 秒不可信时，在同一会话内以最后可信位置为锚点，用后续真实按压时长预测当前位置并执行受像素边界和时间边界共同约束的随机移动；人物外观重新连续 3 帧可信后自动恢复视觉平台保护。

## 行为

- 失信不足 15 秒时只冻结左右移动，随机攻击继续。
- 每段可信视觉移动完成并取得新可信帧后，用动作前后中心 X 差值除以 Broker `actualHoldMs` 生成方向样本。仅接受位移方向一致、位移至少 `2px`、速率位于 `0.05..2.50 px/ms` 的样本；每个方向保留最近 8 个样本并取中位数。左右方向各至少 2 个有效样本才视为已校准。
- 连续失信达到 15 秒且已校准后进入 `FallbackContinuous`。回退只针对新鲜帧中的临时人物身份不可信；未完成校准、观察过期、捕获/预览故障、配置/schema/视口故障、`FacingRestorePending`，或人物身份可信但处于平台外框之外时继续冻结，禁止盲走。上述 fatal 状态立即取消计时并作废像素锚点，恢复可信视觉前不能重新回退。
- 进入回退时以最后可信 `visualOffsetPx` 为像素锚点、以 0 为本段时间偏移。每段实际释放后按对应方向中位 `px/ms * actualHoldMs` 推进预测位置，并按每段至少 `2px`、且不少于预测位移 25% 的量增长不确定度。
- 回退移动保留固定方向顺序、随机保持时长和随机回中，但每个候选必须同时满足：按 `plannedHoldMs..plannedHoldMs + 20ms` 的所有可能实际落点都位于“平台半宽 - 当前保护带 - 预测不确定度”内，并且累计方向按压不超过 `maxLateralMoveMs`。第一段还必须证明存在安全的第二段；没有候选时冻结本轮移动并继续攻击。
- 回退期间视觉观察继续运行。现有身份稳定器连续 3 个新帧恢复可信后，在下一完整移动周期切回视觉保护；不在一对左右动作中间更换策略。
- 回退与视觉保护共用一个攻击会话、Broker 连接、按键状态和攻击节奏，不启动第二个控制器。
- 已保存且通过 schema/视口校验的视觉配置在重新开始时直接复用。启动阶段 3 秒内暂未达到当前人物阈值不再拒绝启动或要求重画，而是进入“继续攻击、移动冻结、持续锁定”；只有配置缺失、schema 非法或视口不匹配才要求重新配置。Broker/UAC 准备完成后、首次攻击输入前必须再次检查最新观察：新鲜的临时身份失信仍允许冻结启动，陈旧观察及 fatal 状态拒绝输入。
- UI 显示“持续攻击回退”并显示预测偏移，日志记录校准样本、进入/离开回退、预测偏移和不确定度。失焦、窗口身份变化、Broker 或释放故障仍立即停止。

## 风险边界

位置预测不能替代实时视觉。校准不足、预测不确定度耗尽安全空间或任何候选无法同时通过像素与时间边界时必须冻结移动；视觉恢复后立即用真实位置纠正预测误差。该策略显著降低识别短时丢失时的漂移风险，但不能宣称绝对不会掉落。
