# 视觉失锁双边界回退设计

日期：2026-08-26

## 目标

视觉增强持续攻击在人物连续失信 15 秒后继续随机攻击和左右移动。视觉已积累足够运动样本时，回退移动必须同时受真实累计毫秒边界与预测平台像素边界保护，避免仅靠毫秒模型长期漂移出平台。

## 已确认方案

采用混合回退：

1. 视觉可信期间，每次完成方向移动并取得新可信帧后，持续采集该方向的 `displacementPx / actualHoldMs`。
2. 左右各 2 个有效样本只是启用像素预测的最低门槛。达到门槛后不停止采样，每侧维护最近 32 个有效样本并使用中位数。
3. 视觉连续失信 15 秒且已经标定时，实际动作改由像素感知回退规划器生成。随机候选必须同时通过毫秒和像素两套边界预演。
4. 尚未标定时继续使用普通毫秒规划器，但只从配置按压范围的下半段随机选择。没有安全候选时只冻结当前移动轮，不停止攻击会话。
5. 视觉重新连续可信后，只在完整移动周期边界切回视觉控制，并用真实像素位置和当前累计毫秒重新锚定预测器。

## 边界模型

毫秒边界使用当前会话的 `relativeOffsetMs` 和配置 `maxLateralMoveMs`。像素边界使用最后可信 `visualOffsetPx`、按方向滚动中位数得到的 `pixelsPerMs`、当前不确定度和平台宽度扣除保护带后的可用半宽。

每次预测移动后：

```text
predictedPx = currentPx + direction * pixelsPerMs * actualHoldMs
uncertaintyPx = currentUncertaintyPx + max(2, abs(deltaPx) * 0.25)
predictedMs = currentMs + direction * actualHoldMs
```

候选只有在 `abs(predictedMs) <= maxLateralMoveMs` 且 `abs(predictedPx) + uncertaintyPx <= usableHalfWidthPx` 时合法。与现有规划器一致，候选还要预留最多 20ms 的释放延迟，并保证第一段的全部允许实际时长仍存在合法第二段。

## 持续校准

有效样本要求：实际按压在合法范围内、方向位移为正、绝对位移至少 2px、速率处于 `0.05..2.50 px/ms`。有效样本进入对应方向最近 32 个样本的滚动窗口；无效样本不影响中位数，但同样记录诊断。

本期不把换算关系跨人物模板、视口或平台自动持久化。完整日志为后续离线分析提供数据，未来只有在能按人物模板版本、视口和平台上下文建立稳定版本化事实时才考虑固化。

## 控制器数据流

```text
可信视觉移动完成
-> Broker 返回 actualHoldMs
-> 新可信帧返回 afterCenterX
-> 校准器记录接受/拒绝样本并更新方向中位数
-> 最新真实 visualOffsetPx + relativeOffsetMs 重锚定预测器

连续失信达到 15s
-> 已标定：双边界回退规划器随机选择合法动作
-> 未标定：保守毫秒规划器随机选择合法动作
-> 执行动作并使用 Broker 真实时长提交时间 offset
-> 已标定分支同时推进预测像素与不确定度

视觉恢复
-> 完成当前移动周期
-> 用真实像素位置和当前时间 offset 重锚定
-> 下一周期恢复视觉授权
```

## 结构化日志

每个校准尝试记录：会话、周期、方向、请求/实际按压毫秒、动作前后 X、位移、候选速率、接受/拒绝代码、左右有效样本数、左右当前中位数。

每个回退决策和完成动作记录：使用的规划器、方向、随机候选按压、预测前后像素 offset、预测前后不确定度、时间 offset、毫秒边界、像素可用半宽、裁剪或冻结代码、Broker 实际按压毫秒。

日志写入失败不得中断输入会话。React 日志弹窗仍只读取允许公开的字段，不新增路径或逐帧像素传输。

## 异常路径

- 标定不足：使用保守毫秒回退，不因缺少样本停止攻击。
- 双边界无合法候选：冻结本轮移动并继续攻击。
- Broker 实际时长非法：沿现有安全路径停止并释放全部按键。
- 预测器状态越过任一硬边界：拒绝后续动作，不以异常继续盲走。
- 视觉恢复：真实观察覆盖预测像素，但保留当前真实累计毫秒。
- `OutsideFrozen`：始终禁止回退盲走。

## 测试

- 校准器达到 2+2 后标定成功，随后第 3 至第 32 个样本继续更新中位数，第 33 个淘汰最旧样本。
- 所有接受和拒绝原因都产生结构化遥测。
- 控制器在已标定回退中使用像素规划器实际生成动作，而不是仅发布预测值。
- 像素边界会裁掉毫秒合法但像素不合法的随机候选。
- 未标定回退仍继续攻击，并只使用配置按压范围下半段。
- 无安全候选只冻结本轮移动；视觉恢复后在周期边界以真实像素和当前毫秒重新锚定。
- 完整 Core、Host、Broker 和前端测试保持通过。
